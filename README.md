# Subscrypts Documentation

This repository contains the versioned source of the official Subscrypts documentation, published at **[docs.subscrypts.com](https://docs.subscrypts.com)**.

[Subscrypts](https://subscrypts.com) is a decentralized subscription platform on Arbitrum One that lets merchants accept recurring crypto payments through smart contracts, with no personal data required and a 1% platform fee.
