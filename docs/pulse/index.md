# Subscrypts Pulse

[Subscrypts Pulse](https://pulse.subscrypts.com) is a real-time subscription monitoring application for the Subscrypts protocol on Arbitrum One. It tracks your subscriptions, monitors balances, and sends push notifications — all without requiring private keys or app store downloads.
