# Subscrypts Telegram Bot

The [Subscrypts Telegram Bot](https://telegram.onsubscrypts.com) is a multi-tenant automation bot that connects on-chain subscription state to Telegram group membership management. It enables group and channel owners to monetize their communities with blockchain-powered access control.
